\cmapagent\ demonstrates a practical agentic retrieval-augmented architecture for scientific data systems, coupling retrieval over a curated catalog and its associated scientific literature with explicit, tool-mediated execution and artifact-centric outputs.
By grounding dataset and variable selection in catalog descriptors and the methodological context contained in the literature that documents each dataset, the system reduces the translation burden from scientific intent to executable analysis while preserving an auditable trace from question to result.
A preliminary characterization of the retrieval substrate indicates that this design surfaces the relevant evidence reliably for technically specific queries, and a more comprehensive end-to-end evaluation, curated with domain scientists, is in preparation.
More broadly, the work illustrates a path for tightly coupling a domain-specific data catalog with the scientific literature that explains it, so that natural-language interaction can move beyond catalog lookup toward grounded, reproducible analysis.
