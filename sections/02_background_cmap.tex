This section will summarize the \cmap\ data layer only as needed to contextualize the agentic system.
\cmap\ harmonizes heterogeneous datasets into a common structure and indexes entries by location and time, enabling efficient retrieval and integration. The system exposes these capabilities via interactive and programmatic interfaces.

\paragraph{Curation and harmonization as a substrate for agents.}
CMAP is assembled through domain-scientist curation: ingest and documentation practices standardize metadata, references, and variable semantics across heterogeneous sources.
For an agentic interface, this curated substrate matters because retrieval can anchor decisions in vetted descriptors (e.g., units, coverage, provenance) and tools can operate on consistent identifiers.
In what follows we treat these properties as a scientific enabler of reliable discovery and integration rather than as an implementation detail.

\paragraph{Motivation for an agentic layer.}
Although \cmap\ provides graphical and programmatic interfaces, users often still face:
(i) dataset discovery across a large catalog,
(ii) variable-name resolution, and
(iii) assembly of multi-step workflows (e.g., retrieve $\rightarrow$ visualize $\rightarrow$ integrate $\rightarrow$ analysis).
\cmapagent\ is designed to reduce these frictions by coupling semantic retrieval with explicit tool execution.
