Figure~\ref{fig:architecture} summarizes the \cmapagent\ architecture at the level of abstraction relevant to scientific workflows: retrieval over a domain knowledge base, agentic planning with tool-mediated execution, and artifact-oriented outputs with persisted provenance.

The system is designed to translate open-ended scientific intent into a sequence of verifiable operations: dataset and variable resolution, spatiotemporal subsetting, optional integration of multiple datasets, computation, and visualization.
Rather than asking users to learn internal catalog identifiers and calling conventions, the agent performs these steps while exposing intermediate decisions through tool traces and returned artifacts.
Two mechanisms together make this possible while preserving verifiability.
First, retrieval over a curated knowledge base provides domain context---catalog entries, variable semantics, and usage guidance---to reduce hallucination and improve correct dataset selection.
Second, analyses are executed through explicit tools with constrained inputs and programmatic validation, so that computations and figures are produced by deterministic routines rather than synthesized from the language model's free-form text generation.

Because intermediate steps are carried out by these tools, outputs can be centered on scientific artifacts: subsets of data, figures, and (where appropriate) reusable code snippets that reproduce the same operations in the CMAP software ecosystem.
This design supports interactive exploration while enabling transition to scripted workflows for reproducible analyses.
The architecture is realized as a concrete software stack, but the scientific claims in this paper emphasize capability and behavior rather than the specifics of frameworks or deployment---a separation that matters for long-lived scientific infrastructure, where engineering choices may evolve while the user-facing semantics and provenance guarantees should remain stable.
