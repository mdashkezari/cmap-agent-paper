\cmapagent\ is an agentic, retrieval-augmented interface for interacting with the Simons Collaborative Marine Atlas Project (CMAP) harmonized ocean and atmospheric data system.
The system enables users to express scientific intent in natural language and obtain verifiable results through a combination of
(i) retrieval over a knowledge base derived from \cmap\ catalog metadata, supporting documentation, and the full-text scientific literature associated with individual datasets,
(ii) tool-based execution---invoking validated, purpose-built routines for dataset discovery, data subsetting, visualization, and dataset colocalization ---and
(iii) optional emission of executable Python code that reproduces the analysis carried out by the agent.
The contribution is a practical, domain-oriented agent design that couples LLM-driven planning with validated scientific tools and artifact-centric outputs (i.e., responses whose primary deliverables are downloadable data subsets, figures, and code),
reducing the barrier from question to executable analysis while supporting provenance and reproducibility.
Representative workflows and an evaluation framework are outlined for marine and environmental-science use cases.
