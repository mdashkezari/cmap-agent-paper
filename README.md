# CMAP Agent Paper

This repository contains manuscript for an academic journal article describing **CMAP Agent**:
Agentic retrieval-augmented interface for dataset discovery, access, integration, and analysis on **Simons CMAP** data platform.


## Structure

- `cmap_agent.tex`: main entry point
- `sections/`: paper sections
- `figures/`: figures
- `bib/references.bib`: bibliography
